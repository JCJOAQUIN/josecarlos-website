# 🚀 Getting Started

## Prerequisites

- Node.js 24+
- npm 11+
- Angular CLI 21+

---

## Installation

Clone the repository:

```bash
git clone https://github.com/JCJOAQUIN/josecarlos-website.git
```

Install dependencies:

```bash
npm install
```

---

## Development Server

```bash
ng serve
```

Open your browser at:

```
http://localhost:4200
```

---

## Build

```bash
ng build
```

---

## Server-Side Rendering (SSR)

```bash
npm run serve:ssr
```
